# 获取书籍列表接口

## 接口地址

```http
POST /api/v1/book/list
```

## 请求方式

POST

## 请求`Header`

无

## 请求示例

```json
{
    "planet": {
        "id": "1"
    }
}
```

## 请求参数

|  参数名  |   类型   | 必填 |   说明   |
|:--------:|:--------:|:----:|:--------:|
| `planet` | `Object` |  是  | 天体对象 |

### `planet`部分参数说明

| 参数名 | 类型  | 必填 |    说明    |
|:------:|:-----:|:----:|:----------:|
|  `id`  | `string` |  是  | 天体 ID，取正 `int64` 的十进制字符串，范围为 1 到 9223372036854775807 |

使用天体简介接口返回的 ID 原文，JSON 中用双引号包围，例如 `"9007199254740993"`。

## 响应参数

|:---------:|:--------:|:--------:|
|  `code`   |  `int`   |  状态码  |

|  `data`   | `object` | 返回数据 |

## `data`部分参数说明

|   参数名   |      类型       |   说明   |
|:----------:|:---------------:|:--------:|
| `bookList` | `Array<Object>` | 书籍列表 |
