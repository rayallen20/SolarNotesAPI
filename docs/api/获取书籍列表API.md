# 获取书籍列表接口

## 接口地址

```http
POST /api/v1/book/list
```

一次返回指定天体下全部可见书籍（`display_status = 'visible'`），无需分页。书单仅按管理员设置的 `book.sort` 升序排列。可见书籍即使尚未添加目录或文章，也会列出。

## 请求方式

POST

## 请求`Header`

无

## 请求示例

```json
{
    "planet": {
        "id": "9007199254740993"
    }
}
```

## 请求参数

|  参数名  |   类型   | 必填 |   说明   |
|:--------:|:--------:|:----:|:--------:|
| `planet` | `Object` |  是  | 天体对象 |

### `planet`部分参数说明

| 参数名 | 类型  | 必填 |    说明    |
|:------:|:-----:|:----:|:----------:|
|  `id`  | `string` |  是  | 天体 ID，取正 `int64` 的十进制字符串，范围为 1 到 9223372036854775807 |

使用天体简介接口返回的 ID 原文，JSON 中用双引号包围，例如 `"9007199254740993"`。

## 响应示例

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "bookList": [
            {
                "id": "9007199254740995",
                "title": "操作系统入门"
            },
            {
                "id": "9007199254740997",
                "title": "进程与调度"
            }
        ]
    }
}
```

## 响应参数

|  参数名   |   类型   |   说明   |
|:---------:|:--------:|:--------:|
|  `code`   |  `int`   |  状态码  |
| `message` | `string` | 提示信息 |
|  `data`   | `object` | 返回数据 |

## `data`部分参数说明

|   参数名   |      类型       |   说明   |
|:----------:|:---------------:|:--------:|
| `bookList` | `Array<Object>` | 书籍列表 |

### `bookList`部分参数说明

| 参数名  |   类型   |   说明   |
|:-------:|:--------:|:--------:|
|  `id`   | `string` | 书籍 ID，正 `int64` 的十进制字符串。获取目录时将它原样传入 `book.id` |
| `title` | `string` | 书籍标题 |

## 空书单与错误响应

天体存在但没有书籍，或该天体下所有书籍都已隐藏时，返回成功空书单。

```json
{"code": 200, "message": "success", "data": {"bookList": []}}
```

以下响应的 HTTP 状态均为 200，错误体的 `data` 均为 `{}`。

| 业务码 | 情形 | `message` |
|:-------|:-----|:----------|
| `10101` | 请求 JSON 不合法，或 `planet.id` 缺失、为裸数字、不是正十进制整数或超出 `int64` 范围 | 参数校验提示 |
| `20102` | `planet.id` 格式正确，但天体不存在 | 所选天体不存在,请刷新天体列表 |
| `10201` | 数据库查询或事务失败 | 数据库操作失败,请稍后重试 |
| `500` | 其他服务内部错误 | 服务暂时不可用,请稍后重试 |
