# 获取文章接口

## 接口地址

```http
POST /api/v1/article/show
```

## 请求方式

POST

## 请求`Header`

无

## 请求示例

```json
{
    "catalogue": {
        "id": 1
    }
}
```

## 请求参数

|   参数名    |   类型   | 必填 |   说明   |
|:-----------:|:--------:|:----:|:--------:|
| `catalogue` | `object` |  是  | 目录对象 |

### `catalogue`部分参数

| 参数名 | 类型  | 必填 |  说明  |
|:------:|:-----:|:----:|:------:|
|  `id`  | `int` |  是  | 目录id |
