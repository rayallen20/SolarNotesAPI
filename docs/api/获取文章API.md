# 获取文章接口

## 接口地址

```http
POST /api/v1/article/show
```

## 请求方式

POST

## 请求`Header`

无

## 请求示例

```json
{
    "catalogue": {
        "id": "2123684178049376261"
    }
}
```

## 请求参数

|   参数名    |   类型   | 必填 |   说明   |
|:-----------:|:--------:|:----:|:--------:|
| `catalogue` | `object` |  是  | 目录对象 |

### `catalogue`部分参数

| 参数名 | 类型  | 必填 |  说明  |
|:------:|:-----:|:----:|:------:|
| `id` | `string` | 是 | 目录树中所选文件的 ID，取正 `int64` 的十进制字符串，范围为 1 到 9223372036854775807。 |

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "article": {
```

## 响应参数

|  参数名   |   类型   |   说明   |
|:---------:|:--------:|:--------:|
|  `code`   |  `int`   |  状态码  |
| `message` | `string` | 提示信息 |
|  `data`   | `object` | 返回数据 |

## `data`部分参数说明

|  参数名   |   类型   |   说明   |
|:---------:|:--------:|:--------:|
| `article` | `Object` | 文章对象 |

### `article`部分参数说明

|   参数名    |   类型   |     说明     |
|:-----------:|:--------:|:------------:|
| `id` | `string` | 文章行的主键 `article.id`，使用正 `int64` 的十进制字符串。请求中的 `catalogue.id` 用于定位关联文章。 |
| `content` | `string` | 源文件的 Markdown 正文，本地图片目标已改写为可访问的资源 URL。 |
| `createdAt` | `string` | 文章行 `article.created_at` 的日历日期，格式为 `YYYY-MM-DD`。 |

## 正文和图片

读者从公开目录树选中 `type` 为 `file` 的节点后，将该节点的 ID 原样传入 `catalogue.id`。接口检查所属书籍、文件和所有祖先均已公开，并沿用目录接口对小写 `img` 文件夹整条分支的过滤规则。直接使用节点 ID 请求也执行相同检查。[获取目录 API](获取目录API.md)

源文件中的图片引用为 `![查询请求执行过程](./img/查询请求执行过程.jpg)`。接口以正文所在目录解析相对图片路径，保留从资源根开始的各级目录，使用 `asset.base_url` 生成绝对 URL。上例的中文路径和空格均已按 URL 路径分量编码。以 `/` 开头的本地引用相对于资源根解析，查询参数和片段一并保留。

改写适用于 Markdown 行内图片、引用式图片和 HTML 的 `<img src>`。完整的 HTTP(S) 图片、协议相对图片、普通链接和代码示例保持原文。合法的本地图片尚未落盘时仍返回正文及图片 URL，浏览器请求该图片时可能收到 404。

## 响应码

接口的 HTTP 状态均为 200。调用方通过响应体 `code` 判断结果，失败时 `data` 为 `{}`。

| 业务码 | 含义 |
|:-----:|:-----|
| `200` | 返回公开文章的 ID、正文和创建日期。 |
| `10101` | 请求缺少对象或 ID，或 ID 不是正 `int64` 的十进制字符串，例如裸数字、零、负数、小数或越界值。 |
| `20401` | 文章不存在或暂不可读。适用于节点或文章缺失、节点为文件夹、书或节点未公开、位于被过滤的分支，以及正文文件缺失、格式或编码无效、本地图片目标越界等情况。 |
| `10201` | 数据库连接、查询或事务失败。 |
| `500` | 目录数据损坏、存储根未挂载、意外 I/O 或其他内部错误。 |

```json
{"code":20401,"message":"文章不存在或暂不可读","data":{}}
```
