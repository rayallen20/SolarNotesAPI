获取文章 API 实现方案

读者点选公开目录树中的文件时，接口使用叶节点 ID 查找文章，读取 UTF-8 Markdown，将本地图片引用改写为 Nginx 可访问的绝对 URL，最后返回文章自身的 ID、正文和创建日期。

本轮已更新开发、生产和示例配置及其加载校验。下文的文章处理代码供开发前评审；当前运行的文章接口仍返回 mock。

Nginx 映射与已生效的配置

通过 SSH 在 192.168.1.60 检查 nginx -T 的生效配置，定位到 /etc/nginx/sites-enabled/solar-assets.conf。以下是与图片路径有关的有效指令。

server {
    listen 8080;
    server_name _;
    root /solar-notes-data;
    location ~ /\. { deny all; }
    location ~* \.md$ { deny all; }
    location / { try_files $uri =404; }
}

URL 的 / 直接对应文件树 /solar-notes-data/。保留从这个根到图片的全部子目录，去掉物理根前缀。Nginx 拒绝隐藏路径和 Markdown 文件，因此 API 进程直接从可读文件系统取正文，浏览器只向资源站取图。

三份 YAML 共用以下配置

asset:
  base_url: "http://192.168.1.60:8080"

storage:
  root_dir: "/solar-notes-data"

conf.Load() 按 SOLAR_NOTES_ENV 加载开发或生产配置，继续严格检查 YAML 字段。新增的 cfg.Asset.BaseURL 是带主机的 HTTP(S) 地址，可含路径前缀，加载后去尾斜杠，不接受用户信息、查询串或片段。cfg.Storage.RootDir 必须为绝对路径，实际读文章时再打开目录。开发与生产各使用本地配置文件，示例在版本库中提供同样的资源映射。已有部署更新程序时，要在对应环境的 YAML 同步补入这两段。

部署条件　实库中 38 条公开文章记录的 article.path 均为 /solar-notes-data/... 绝对路径。本机目前没有这个挂载点。联调时可在已有文件树的服务器运行 API，或让 API 在同一绝对路径看到只读挂载。单独更改图片域名不能提供正文文件。今后若写入根相对路径，候选读取器同样支持。

先取正文的父目录，再解析相对图片路径，随后剥离存储根，将每个路径分量按 URL 规则编码并用 / 连接。这样中文和空格可正常访问，已编码的字符也不会被重复编码。图片的查询参数与片段随地址保留。

正文写法候选行为
Markdown 行内图片支持相对路径、根相对路径、尖括号目标、标题，以及现有后台兼容的简单单行裸空格文件名。以文章目录解析相对路径，以资产根解析以 / 开头的路径。
引用式图片将用到本地路径的图片引用展开为行内图片。普通链接即使共用同一引用定义，也保留原定义及效果。
HTML 图片处理 Markdown 中实际 HTML 标签的 <img src>，修改本地 src 时保留同标签的其他属性。HTML 改写限于 img[src]，其他图片机制如 srcset、picture/source 和 CSS 背景不在此次改写范围内。当前两份有图的正文均使用 Markdown 图片语法。
已可访问的外部图片完整的 HTTP(S) 或协议相对地址按原文保留。服务端处理正文时不下载外部图片。
普通链接和示例代码解析 Markdown 的语法位置，保留普通超链接、行内代码、代码块、换行和原有排版。
无效和缺失路径拒绝越出存储根、经符号链接指向根外、隐藏路径和指向 Markdown 文件的本地图片目标。合法路径的图片尚未落盘时仍生成目标 URL，读者可继续看正文，图片请求由 Nginx 返回 404。

前端拿到的是 Markdown。后端解析器只定位并替换图片目标。阅读页继续使用 DOMPurify 清洗最终渲染的 HTML。

文章数据、可见性与错误语义

  1. 控制器复用现有 ShowReq。绑定和验证通过后，将 c.Request.Context() 与目录 ID 传给业务层。
  2. DAO 开启只读 REPEATABLE READ 事务，按 article.catalogue_id = catalogue.id 联表查找文件和它所属的书，要求书与文件均公开。使用唯一索引 uk_catalogue_id 取得文章行，包括文章自己的主键、存储路径和创建时间。
  3. 在同一快照内读取这本书的目录行，两处接口共用按 sort ASC 的读取函数。业务层复用现有 buildCatalogueTree，只有请求 ID 对应公开树中的 file 才打开正文。因此直接手填 ID 也要通过相同的祖先显隐及 img 文件夹过滤规则。这一版每次读取的目录数据量与本书节点数成正比。
  4. 数据库事务结束后才访问磁盘。读取器使用 os.Root，校验扩展名、文件类型、根边界和 UTF-8 编码，重写图片后返回正文。响应只暴露 id、content、createdAt。
场景业务码对外表现
授权成功，Markdown 可读取200返回文章。合法空正文用空字符串表示。
请求缺字段、ID 为裸数字、零、负数或超出 int64 上限10101沿用现有参数错误及空 data。
条目或文章缺失、节点为目录、书或祖先隐藏、节点在 img 资源分支内20401统一返回“文章不存在或暂不可读”。公开响应不会区分这些情况。
源文件不存在、不是允许的 Markdown 文件、UTF-8 无效或图片目标不符合读取规则20401同一不可读响应。缺少单张合法图片按上一节单独处理。
数据库连接、查询与事务出错10201现有数据库错误响应。
目录结构损坏、存储根未挂载、意外 I/O 或内部错误500现有内部错误响应。

HTTP 状态沿用项目约定，均为 200。失败响应的 data 为 {}。20401 沿用后台文章不可预览的码值，在公开接口中合并各类不可读原因。

package article

import (
	"errors"
	"net/http"
	"strconv"
	"time"

	"SolarNotesAPI/biz"
	reqArticle "SolarNotesAPI/param/req/v1/article"
	respArticle "SolarNotesAPI/param/resp/v1/article"
	"SolarNotesAPI/resp_body"
	"SolarNotesAPI/sys_error"

	"github.com/gin-gonic/gin"
)

func Show(readMarkdown func(string) (string, error)) gin.HandlerFunc {
	return func(c *gin.Context) {
		var req reqArticle.ShowReq
		var body resp_body.RespBody
		if err := c.ShouldBindJSON(&req); err != nil {
			body.ValidateFailed(err)
			c.JSON(http.StatusOK, body)
			return
		}
		a, err := biz.ReadArticle(c.Request.Context(), req.Catalogue.ID, readMarkdown)
		if err != nil {
			var dbErr *sys_error.DatabaseError
			switch {
			case errors.Is(err, sys_error.ArticleUnavailableErr):
				body.ArticleUnavailableError()
			case errors.As(err, &dbErr):
				body.DBError()
			default:
				body.InternalError()
			}
			c.JSON(http.StatusOK, body)
			return
		}
		body.Success(map[string]any{"article": respArticle.ShowResp{
			ID:        strconv.FormatInt(a.ID, 10),
			Content:   a.Content,
			CreatedAt: a.CreatedAt.Format(time.DateOnly),
		}})
		c.JSON(http.StatusOK, body)
	}
}

package model

import (
	"context"
	"database/sql"
	"errors"
	"time"

	"SolarNotesAPI/db"

	"gorm.io/gorm"
)

var ArticleNotFoundErr = errors.New("article not found")

// Article holds the article metadata and its catalogue node's owning book ID.
type Article struct {
	ID        int64     `gorm:"column:id"`
	BookID    int64     `gorm:"column:book_id"`
	Path      string    `gorm:"column:path"`
	CreatedAt time.Time `gorm:"column:created_at"`
}

// ReadArticleSnapshot reads metadata and the book's tree in a single snapshot.
func ReadArticleSnapshot(ctx context.Context, catalogueID int64) (Article, []Catalogue, error) {
	if db.DB == nil {
		return Article{}, nil, errors.New("database connection is not initialized")
	}
	var row Article
	var nodes []Catalogue
	opts := &sql.TxOptions{Isolation: sql.LevelRepeatableRead, ReadOnly: true}
	err := db.DB.WithContext(ctx).Transaction(func(tx *gorm.DB) error {
		err := tx.Table("article").
			Select("article.id, article.path, article.created_at, catalogue.book_id").
			Joins("JOIN catalogue ON catalogue.id = article.catalogue_id").
			Joins("JOIN book ON book.id = catalogue.book_id").
			Where("catalogue.id = ? AND catalogue.type = ? AND catalogue.display_status = ? AND book.display_status = ?",
				catalogueID, "file", "visible", "visible").
			Take(&row).Error
		if errors.Is(err, gorm.ErrRecordNotFound) {
			return ArticleNotFoundErr
		}
		if err != nil {
			return err
		}
		nodes, err = readCatalogueRows(tx, row.BookID)
		return err
	}, opts)
	if err != nil {
		return Article{}, nil, err
	}
	return row, nodes, nil
}

biz/article.go

检验完整的公开路径。只有确认是可读叶节点，才调用文件读取器。

package biz

import (
	"context"
	"errors"
	"time"

	"SolarNotesAPI/articlecontent"
	"SolarNotesAPI/model"
	"SolarNotesAPI/sys_error"
)

type Article struct {
	ID        int64
	Content   string
	CreatedAt time.Time
}

// ReadArticle accesses storage only after the requested file is found in the public tree.
func ReadArticle(ctx context.Context, catalogueID int64, readMarkdown func(string) (string, error)) (*Article, error) {
	if ctx == nil || catalogueID <= 0 || readMarkdown == nil {
		return nil, &sys_error.InternalError{Cause: errors.New("invalid article read arguments")}
	}
	row, nodes, err := model.ReadArticleSnapshot(ctx, catalogueID)
	if errors.Is(err, model.ArticleNotFoundErr) {
		return nil, sys_error.ArticleUnavailableErr
	}
	if err != nil {
		return nil, &sys_error.DatabaseError{Cause: err}
	}
	root, err := buildCatalogueTree(row.BookID, nodes)
	if errors.Is(err, sys_error.CatalogueNotFoundErr) {
		return nil, sys_error.ArticleUnavailableErr
	}
	if err != nil {
		return nil, &sys_error.InternalError{Cause: err}
	}
	if !containsPublicFile(root, catalogueID) || row.Path == "" {
		return nil, sys_error.ArticleUnavailableErr
	}
	if row.ID <= 0 || row.CreatedAt.IsZero() {
		return nil, &sys_error.InternalError{Cause: errors.New("invalid article metadata")}
	}
	content, err := readMarkdown(row.Path)
	if errors.Is(err, articlecontent.ErrUnavailable) {
		return nil, sys_error.ArticleUnavailableErr
	}
	if err != nil {
		return nil, &sys_error.InternalError{Cause: err}
	}
	return &Article{ID: row.ID, Content: content, CreatedAt: row.CreatedAt}, nil
}

func containsPublicFile(root *CatalogueNode, id int64) bool {
	stack := []*CatalogueNode{root}
	for len(stack) > 0 {
		last := len(stack) - 1
		node := stack[last]
		stack = stack[:last]
		if node.ID == id {
			return node.Type == "file"
		}
		stack = append(stack, node.Children...)
	}
	return false
}

打开正文、验证根边界、处理文件不可用，并将图片相对路径映射到公开基址。

package articlecontent

import (
	"errors"
	"fmt"
	"io"
	"io/fs"
	"net/url"
	"os"
	"path/filepath"
	"strings"
	"syscall"
	"unicode/utf8"
)

// ErrUnavailable identifies unavailable Markdown files and invalid local image references.
var ErrUnavailable = errors.New("article content unavailable")

// Reader shares immutable settings across requests.
type Reader struct {
	rootDir string
	base    *url.URL
}

func New(rootDir, publicBaseURL string) (*Reader, error) {
	if !filepath.IsAbs(rootDir) {
		return nil, errors.New("storage.root_dir must be absolute")
	}
	base, err := url.Parse(publicBaseURL)
	if err != nil || (base.Scheme != "http" && base.Scheme != "https") || base.Host == "" ||
		base.User != nil || base.RawQuery != "" || base.ForceQuery || base.Fragment != "" {
		return nil, errors.New("asset.base_url must be an absolute HTTP(S) resource base")
	}
	return &Reader{rootDir: filepath.Clean(rootDir), base: base}, nil
}

type articleSource struct {
	root       *os.Root
	assetBase  *url.URL
	articleDir string
}

// ReadMarkdown opens a fresh storage root for this request and keeps the original Markdown layout.
func (r *Reader) ReadMarkdown(storedPath string) (string, error) {
	realRoot, err := filepath.EvalSymlinks(r.rootDir)
	if err != nil {
		return "", err
	}
	root, err := os.OpenRoot(realRoot)
	if err != nil {
		return "", err
	}
	defer root.Close()

	source := articleSource{root: root, assetBase: r.base}
	data, err := source.readMarkdown(r.rootDir, storedPath)
	if err != nil {
		return "", err
	}
	return RewriteImages(data, source.imageURL)
}

// readMarkdown 读取 UTF-8 正文, 成功时记下文章所在目录相对于存储根的真实路径.
func (a *articleSource) readMarkdown(rootDir, storedPath string) ([]byte, error) {
	name := storedPath
	if filepath.IsAbs(name) {
		relative, err := filepath.Rel(rootDir, name)
		if err != nil {
			return nil, ErrUnavailable
		}
		name = relative
	}
	if !strings.EqualFold(filepath.Ext(name), ".md") {
		return nil, ErrUnavailable
	}
	actual, err := a.resolveStoragePath(name, false)
	if err != nil {
		return nil, err
	}
	if !strings.EqualFold(filepath.Ext(actual), ".md") {
		return nil, ErrUnavailable
	}
	// Linux 和 macOS 上用 O_NONBLOCK 打开, 避免在 Stat 识别 FIFO 之前阻塞.
	f, err := a.root.OpenFile(actual, os.O_RDONLY|syscall.O_NONBLOCK, 0)
	if errors.Is(err, fs.ErrNotExist) {
		return nil, ErrUnavailable
	}
	if err != nil {
		return nil, err
	}
	defer f.Close()
	info, err := f.Stat()
	if err != nil {
		return nil, err
	}
	if !info.Mode().IsRegular() {
		return nil, ErrUnavailable
	}
	content, err := io.ReadAll(f)
	if err != nil {
		return nil, err
	}
	if !utf8.Valid(content) {
		return nil, ErrUnavailable
	}
	a.articleDir = filepath.Dir(actual)
	return content, nil
}

// resolveStoragePath 解析符号链接并检查根边界. 普通缺图可以保留尚不存在的尾部路径.
func (a *articleSource) resolveStoragePath(name string, allowMissing bool) (string, error) {
	if !filepath.IsLocal(name) || strings.ContainsRune(name, 0) {
		return "", ErrUnavailable
	}
	rootDir := a.root.Name()
	candidate := filepath.Join(rootDir, name)
	var missing []string
	for {
		resolved, err := filepath.EvalSymlinks(candidate)
		if err == nil {
			relative, relErr := filepath.Rel(rootDir, resolved)
			if relErr != nil || !filepath.IsLocal(relative) {
				return "", ErrUnavailable
			}
			for i := len(missing) - 1; i >= 0; i-- {
				relative = filepath.Join(relative, missing[i])
			}
			return relative, nil
		}
		if errors.Is(err, syscall.ENOTDIR) || errors.Is(err, syscall.ELOOP) {
			return "", ErrUnavailable
		}
		if !errors.Is(err, fs.ErrNotExist) || candidate == rootDir {
			return "", err
		}
		if !allowMissing {
			return "", ErrUnavailable
		}
		// 失效的符号链接本身仍有目录项, 普通缺失路径则没有.
		_, statErr := os.Lstat(candidate)
		if statErr == nil {
			return "", ErrUnavailable
		}
		if !errors.Is(statErr, fs.ErrNotExist) {
			return "", statErr
		}
		missing = append(missing, filepath.Base(candidate))
		candidate = filepath.Dir(candidate)
	}
}

// imageURL 将文章引用的本地图片映射到该文件的公开 URL.
func (a *articleSource) imageURL(destination string) (string, error) {
	u, err := url.Parse(destination)
	if err != nil {
		return "", fmt.Errorf("%w: invalid image URI", ErrUnavailable)
	}
	if u.Host != "" && (u.Scheme == "http" || u.Scheme == "https" || u.Scheme == "") {
		return destination, nil
	}
	if u.Scheme != "" || u.Path == "" || strings.Contains(u.Path, "\\") {
		return "", ErrUnavailable
	}
	name := filepath.FromSlash(u.Path)
	if strings.HasPrefix(u.Path, "/") {
		name = strings.TrimPrefix(name, string(filepath.Separator))
	} else {
		name = filepath.Join(a.articleDir, name)
	}
	if !a.isPublicImagePath(filepath.Clean(name)) {
		return "", ErrUnavailable
	}
	actual, err := a.resolveStoragePath(name, true)
	if err != nil {
		return "", err
	}
	if !a.isPublicImagePath(actual) {
		return "", ErrUnavailable
	}
	path := filepath.ToSlash(actual)
	segments := strings.Split(path, "/")
	for i, segment := range segments {
		segments[i] = url.PathEscape(segment)
	}
	result := *a.assetBase
	result.Path = strings.TrimRight(result.Path, "/") + "/" + path
	result.RawPath = strings.TrimRight(a.assetBase.EscapedPath(), "/") + "/" + strings.Join(segments, "/")
	result.RawQuery, result.ForceQuery = u.RawQuery, u.ForceQuery
	result.Fragment, result.RawFragment = u.Fragment, u.RawFragment
	return result.String(), nil
}

// isPublicImagePath 检查 Nginx 对隐藏路径分量和 .md 的限制.
func (a *articleSource) isPublicImagePath(name string) bool {
	if !filepath.IsLocal(name) || strings.EqualFold(filepath.Ext(name), ".md") {
		return false
	}
	for _, segment := range strings.Split(filepath.ToSlash(name), "/") {
		if strings.HasPrefix(segment, ".") {
			return false
		}
	}
	return true
}

package articlecontent

import (
	"bytes"
	"errors"
	"html"

	"strings"

	"github.com/yuin/goldmark/ast"
	"github.com/yuin/goldmark/parser"
	"github.com/yuin/goldmark/text"
	"github.com/yuin/goldmark/util"

// imageEdit 记录一次针对源码字节区间的替换.
type imageEdit struct {
	start, end int    // start 和 end 标记左闭右开的字节范围.
	value      string // value 是新写入的 Markdown 片段.
}

// imageParser 记录 Goldmark 解析图片时消费的源码位置. 每篇文章创建一个实例.
type imageParser struct {
	parser.InlineParser                              // InlineParser 委托给 Goldmark 的标准链接解析器.
	resolve             func(string) (string, error) // resolve 将单个目标转换为公开 URL.
	edits               []imageEdit                  // edits 只收集需要改写的图片.
	err                 error                        // err 保留第一次解析或映射失败的原因.
}

// RewriteImages 重写图片目标, 并按原字节顺序拼回其余正文.
func RewriteImages(source []byte, resolve func(string) (string, error)) (string, error) {
	p := &imageParser{InlineParser: parser.NewLinkParser(), resolve: resolve}
	inlines := parser.DefaultInlineParsers()
	for i, entry := range inlines {
		if entry.Value == p.InlineParser {
			inlines[i].Value = p
		}
	}
	markdown := parser.NewParser(
		parser.WithBlockParsers(parser.DefaultBlockParsers()...),
		parser.WithInlineParsers(inlines...),
		parser.WithParagraphTransformers(parser.DefaultParagraphTransformers()...),
	)
	document := markdown.Parse(text.NewReader(source))
	if p.err != nil {
		return "", p.err
	}
	if err := p.rewriteHTML(document, source); err != nil {
		return "", err
	}
	sort.Slice(p.edits, func(i, j int) bool { return p.edits[i].start < p.edits[j].start })
	var out strings.Builder
	cursor := 0
	for _, edit := range p.edits {
		if edit.start < cursor || edit.end < edit.start || edit.end > len(source) {
			return "", errors.New("invalid Markdown image range")
		}
		out.Write(source[cursor:edit.start])
		out.WriteString(edit.value)
		cursor = edit.end
	}
	out.Write(source[cursor:])
	return out.String(), nil
}

// CloseBlock 转发标准解析器的收尾操作, 防止链接状态跨段落残留.
func (p *imageParser) CloseBlock(parent ast.Node, r text.Reader, ctx parser.Context) {
	p.InlineParser.(parser.CloseBlocker).CloseBlock(parent, r, ctx)
}

// legacyImage 兼容简单单行图片中带裸空格的文件名. 标准标题和尖括号写法交给 Goldmark.
var legacyImage = regexp.MustCompile(`^!\[[^\[\]\\\x60\r\n]*\]\(([^()<>"'\\\t\r\n ]+(?: +[^()<>"'\\\t\r\n ]+)+)\)`)

// Parse 在解析器处理行内语法时定位图片, 记录真正需要替换的区间.
func (p *imageParser) Parse(parent ast.Node, r text.Reader, ctx parser.Context) ast.Node {
	line, start := r.PeekLine()
	if line[0] == '!' {
		if match := legacyImage.FindSubmatchIndex(line); match != nil {
			p.replace(line[match[2]:match[3]], start.Start+match[2], start.Start+match[3], nil)
			r.Advance(match[1])
			return ast.NewString(line[:match[1]])
		}
	}
	lineNo, saved := r.Position()
	node := p.InlineParser.Parse(parent, r, ctx)
	img, ok := node.(*ast.Image)
	if !ok || len(img.Destination) == 0 {
		return node
	}
	endLine, end := r.Position()
	afterLabel := start.Start + 1
	if len(line) > 1 && line[1] == '(' && end.Start > afterLabel {
		// 只定位目标, 保留括号, 标题及其间的排版.
		r.SetPosition(lineNo, saved)
		r.Advance(2)
		r.SkipSpaces()
		_, dest := r.Position()
		from := dest.Start
		if r.Peek() == '<' {
			from++
		}
		r.SetPosition(endLine, end)
		to := from + len(img.Destination)
		if from < 0 || to > len(r.Source()) || !bytes.Equal(r.Source()[from:to], img.Destination) {
			p.err = errors.New("cannot locate Markdown image destination")
			return node
		}
		p.replace(img.Destination, from, to, nil)
	} else {
		// 把这次图片引用展开为行内图片, 普通链接可以继续使用同一份引用定义.
		p.replace(img.Destination, afterLabel, end.Start, img)
	}
	return node
}

// markdownEscape 匹配单个反斜杠标点转义或带分号的字符实体.
var markdownEscape = regexp.MustCompile(`\\[[:punct:]]|&#(?:[0-9]{1,7}|[xX][0-9a-fA-F]{1,6});|&[A-Za-z][A-Za-z0-9]*;`)

// markdownValue 一次解开原文中的转义和实体, 保留 URL 百分号编码及转义后产生的字面文本.
func markdownValue(raw []byte) string {
	return markdownEscape.ReplaceAllStringFunc(string(raw), decodeMarkdownEscape)
}

// decodeMarkdownEscape 保留未知的实体名称, 数字实体按十进制或显式十六进制解码.
func decodeMarkdownEscape(token string) string {
	if token[0] == '\\' {
		return token[1:]
	}
	if token[1] == '#' {
		return html.UnescapeString(token)
	}
	if entity, ok := util.LookUpHTML5EntityByName(token[1 : len(token)-1]); ok {
		return string(entity.Characters)
	}
	return token
}

// urlSyntax 保护目标中的 Markdown 定界符和字符实体.
var urlSyntax = strings.NewReplacer("(", "%28", ")", "%29", "<", "%3C", ">", "%3E",
	" ", "%20", "\\", "%5C", "\r", "%0D", "\n", "%0A", "&", "&amp;")

// replace 仅在目标变化时记录替换, 外部 HTTP(S) 图片可完整保留原文.
func (p *imageParser) replace(raw []byte, start, end int, ref *ast.Image) {
	if p.err != nil {
		return
	}
	value := markdownValue(raw)
	target, err := p.resolve(value)
	if err != nil {
		p.err = err
		return
	}
	if target == value {
		return
	}
	target = urlSyntax.Replace(target)
	if ref != nil {
		if len(ref.Title) > 0 {
			title := html.EscapeString(markdownValue(ref.Title))
			title = strings.NewReplacer("\\", "\\\\", "\r", "&#13;", "\n", "&#10;").Replace(title)
			target += ` "` + title + `"`
		}
		target = "(" + target + ")"
	}
	p.edits = append(p.edits, imageEdit{start: start, end: end, value: target})
}
articlecontent/html.go

定位原生 HTML 图片的 src 属性。

package articlecontent

import (
	"bytes"
	"html"
	"io"
	"regexp"
	"strings"

	"github.com/yuin/goldmark/ast"
	"github.com/yuin/goldmark/text"
	htmltoken "golang.org/x/net/html"
)

// Only raw HTML recognized by the Markdown parser can contain HTML image elements.
func (p *imageParser) rewriteHTML(document ast.Node, source []byte) error {
	var literalElement string
	return ast.Walk(document, func(node ast.Node, entering bool) (ast.WalkStatus, error) {
		if !entering {
			return ast.WalkContinue, nil
		}
		var segments []text.Segment
		switch n := node.(type) {
		case *ast.Image:
			// An image description becomes alt text rather than rendered HTML.
			return ast.WalkSkipChildren, nil
		case *ast.RawHTML:
			segments = n.Segments.Sliced(0, n.Segments.Len())
		case *ast.HTMLBlock:
			lines := n.Lines()
			segments = lines.Sliced(0, lines.Len())
			if n.HasClosure() {
				segments = append(append([]text.Segment(nil), segments...), n.ClosureLine)
			}
		default:
			return ast.WalkContinue, nil
		}
		return ast.WalkContinue, p.rewriteHTMLFragment(segments, source, &literalElement)
	})
}

// Tokenize a contiguous HTML fragment while retaining offsets into the Markdown source.
// Offsets can jump between lines inside a block quote or a list item.
func (p *imageParser) rewriteHTMLFragment(segments []text.Segment, source []byte, literalElement *string) error {
	var fragment []byte
	for _, segment := range segments {
		fragment = append(fragment, source[segment.Start:segment.Stop]...)
	}
	z := htmltoken.NewTokenizer(bytes.NewReader(fragment))
	offset, span, spanStart := 0, 0, 0
	for {
		kind := z.Next()
		if kind == htmltoken.ErrorToken {
			if z.Err() == io.EOF {
				return nil
			}
			return z.Err()
		}
		from := offset
		offset += len(z.Raw())
		if kind != htmltoken.StartTagToken && kind != htmltoken.SelfClosingTagToken && kind != htmltoken.EndTagToken {
			continue
		}
		token := z.Token()
		if *literalElement != "" {
			if kind == htmltoken.EndTagToken && token.Data == *literalElement {
				*literalElement = ""
			}
			continue
		}
		if kind == htmltoken.EndTagToken {
			continue
		}
		switch token.Data {
		case "pre", "code", "script", "style", "textarea", "title":
			*literalElement = token.Data
			continue
		case "img":
		default:
			continue
		}
		for _, attr := range token.Attr {
			if attr.Key != "src" {
				continue
			}
			first, last := htmlImageSource(fragment[from:offset])
			if first < 0 || attr.Val == "" {
				break
			}
			first, last = first+from, last+from
			// Keep the Markdown's list and quote prefixes intact for multiline tags.
			for span < len(segments) && first >= spanStart+segments[span].Stop-segments[span].Start {
				spanStart += segments[span].Stop - segments[span].Start
				span++
			}
			if span == len(segments) || last > spanStart+segments[span].Stop-segments[span].Start {
				break
			}
			url, err := p.resolve(attr.Val)
			if err != nil {
				return err
			}
			if url != attr.Val {
				value := html.EscapeString(url)
				if previous := fragment[first-1]; previous != '"' && previous != '\'' {
					value = strings.NewReplacer("=", "&#61;", "\x60", "&#96;").Replace(value)
				}
				origin := segments[span].Start - spanStart
				p.edits = append(p.edits, imageEdit{start: origin + first, end: origin + last, value: value})
			}
			break // HTML uses the first occurrence of a duplicate attribute.
		}
	}
}

// Consume attributes in order, so src-like text in another attribute is never edited.
var rawHTMLAttr = regexp.MustCompile(`^[\t\n\f\r ]+([^\t\n\f\r />=]+)(?:[\t\n\f\r ]*=[\t\n\f\r ]*(?:"([^"]*)"|'([^']*)'|([^\t\n\f\r >]+)))?`)

func htmlImageSource(raw []byte) (int, int) {
	for offset := len("<img"); offset < len(raw); {
		index := rawHTMLAttr.FindSubmatchIndex(raw[offset:])
		if index == nil {
			break
		}
		if bytes.EqualFold(raw[offset+index[2]:offset+index[3]], []byte("src")) {
			for _, pair := range []int{4, 6, 8} {
				if index[pair] != -1 {
					return offset + index[pair], offset + index[pair+1]
				}
			}
			break
		}
		offset += index[1]
	}
	return -1, -1
}
