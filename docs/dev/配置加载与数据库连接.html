配置加载与数据库连接

SolarNotes 前台 API 启动时先选择环境、校验配置并连接 MySQL。数据库就绪后，Gin 才在配置的端口监听请求。

选择运行环境

用途根目录文件加载条件
开发config.dev.yamlSOLAR_NOTES_ENV 未设置、为空或为 dev
生产config.prod.yamlSOLAR_NOTES_ENV=prod
示例config.example.yaml部署时复制为对应环境的文件，并填写实际连接信息

服务先在可执行文件所在目录查找选中的文件，文件不存在时再查工作目录。指定其他环境值或找不到对应配置时，进程启动失败。开发和生产文件包含实际凭据，由 Git 忽略。

配置字段

service:
  port: "4061"
database:
  host: "127.0.0.1"
  port: "3306"
  user: "solar_notes"
  password: ""
  name: "solar_notes"

service.port 是 HTTP 监听端口。database 中的五个字段均为必填项，两个端口均须在 1–65535 之间。示例中的密码留空，使用前须填写。当前提供的开发和生产连接目标均为 192.168.1.60:3306/solar_notes，两个文件可以独立修改。

从进程启动到 HTTP 就绪

  1. conf 选择环境并解析 YAML。字段名拼错、必填项缺失或端口无效时，返回配置错误。
  2. db 根据配置建立 GORM/MySQL 连接，启用单数表名、utf8mb4 和本地时区的时间解析。连接池最多打开 10 个连接，最多保留 5 个空闲连接，单个连接最长使用 1 小时。
  3. main.go 在连接成功后启动 HTTP 服务。数据库不可达、认证失败或库名不存在时，进程以非零状态退出。连接层只管理数据库连接，业务查询由后续的 DAO 层负责。

启动与验收

在项目根目录选择一条命令启动服务。两个环境默认都监听 4061，切换前先停止当前进程。

# 开发环境
go run .

# 生产环境
SOLAR_NOTES_ENV=prod go run .

在另一终端请求已注册的天体列表接口。收到 HTTP 200 和业务码 200 表示服务已完成数据库初始化并开始处理请求。此阶段的业务数据仍来自现有 mock。

curl -fsS http://127.0.0.1:4061/api/v1/planet/list

配置错误可用 SOLAR_NOTES_ENV=staging go run . 验证。验证连接失败时，可将示例复制到临时目录，与编译后的二进制放在一起，填写测试凭据并指定一个未监听的数据库端口。预期两种情况都在 HTTP 开始监听前退出。

本次验收结果　开发和生产配置均已实际连接 solar_notes，天体列表接口在两次启动中均返回 HTTP 200 和业务码 200。缺少配置文件、环境值无效、密码为空、端口越界和数据库不可达时，服务均在监听前退出。
