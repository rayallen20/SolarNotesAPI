POST /api/v1/catalogue/show · 评审稿

获取目录 API 实现方案

读者从书单打开一本书时，服务用书籍 ID 查询 solar_notes，返回一棵可阅读的目录树。当前控制器校验请求后返回固定目录。本次拟替换该 mock，并让真实目录节点 ID 能一直传到文章请求。

接口契约组树与排序空目录与错误后端候选代码前端逐文件差异验证与联调

接口契约

书单的 data.bookList[].id 原样传入 book.id。响应的 data.catalogue 是单一根对象。树上每个 id 均为对应目录行的主键，和书籍 ID 分属两张表。对外 ID 统一为正 int64 的十进制字符串，最大值为 9223372036854775807。

目录请求

浏览器发送 JSON，请求头使用 Content-Type: application/json。现有路由入口和目录请求结构可直接复用。

{"book":{"id":"9007199254740995"}}

数据库读取、组树与排序

  1. 在同一个只读 REPEATABLE READ 事务中确认 book.id 存在且 book.display_status = 'visible'，再按 catalogue.book_id 读取该书的全部目录行。请求上下文贯穿两次查询。整树取完即可结束事务，随后在内存中组树。
  2. 目录行按 sort ASC 查询。按父 ID 将行依次追加到各自的子项列表，每个列表自然按数值升序。不同父项允许使用相同序号。同父项已分配的序号唯一，隐藏项占位造成的跳号保留。文件和文件夹参与同一次排序。
  3. 校验所有行。非空目录必须有唯一的 parent_id = 0 根，类型为 folder，且 sort = 0。非根必须挂在同书的文件夹下，序号为正数，或处于 sort IS NULL 且隐藏的待排状态。非法类型、状态、重复 ID、重复序号、孤儿和无法从根访问的环均属于数据错误。
  4. 从根向下遍历。节点及其所有祖先均为 visible 才可公开。名称严格等于小写 img 的文件夹会连同整支子树排除。名为 img 的文件和名为 IMG 的普通文件夹遵循正常显隐规则。隐藏父项下即便有可见子项，也不会将子项提到上一层。
响应字段取值与依据
id / type / name分别取目录行的 id / type / name。本稿按“节点名称”的契约取根行的 catalogue.name。表注释约定它与书名相同，但后台改书名只更新 book.title，因此改名后，读者可能看到书单标题与目录根名称不同。这是需要确认的展示口径。
intro取文件夹的 catalogue.intro。根行存书籍简介，子文件夹行存该章节简介。
createdAt取该文件夹行的 catalogue.created_at。本地结构快照定义为 DATETIME NOT NULL。现有 MySQL 连接已启用 ParseTime，直接按原日历日期输出 YYYY-MM-DD。
children仅文件夹携带，元素为直接公开子项。父 ID、显隐状态和序号仅用于查询和组树。

结构依据为本地 solar_notes_2026-11-19.sql 的 catalogue 建表定义，其中 uk_book_parent_sort 约束同书同父已分配序号的唯一性。后台实现可参见 目录快照读取、树校验及 img 规则、同级序号和书籍重命名。

空目录与错误响应

建议采用以下约定。可见根即使没有公开子项，读者仍能看到它的名称和简介。可见书籍没有公开根时，返回业务码 20301，现有阅读页进入“加载失败”，可点击“重试”。这项约定保留成功响应的单根结构，也使前端能够区分“空文件夹”和“没有可读目录”。

场景业务码返回内容
合法可见根，含零个或多个公开子项200data.catalogue 为根对象，空子项为 []。
缺少请求对象或 ID，或 ID 为裸数字、零、负数、小数、溢出值10101沿用参数校验消息。
书籍缺失或已隐藏20202书籍不存在或未公开。
可见书尚无目录行，或合法根被隐藏、属于 img 资源目录20301这本书暂无公开目录。
非空目录结构损坏，包括隐藏分支内的结构错误500服务暂时不可用，仅返回公开消息。
数据库连接、查询或事务失败10201数据库操作失败，仅返回公开消息。

上述结果的 HTTP 状态均为 200，由响应体 code 表示业务结果。失败统一返回 data: {}。前台拟沿用后台书籍缺失和目录缺失的码值，公开语义如表所示。后台响应码定义

{"code":20301,"message":"这本书暂无公开目录","data":{}}

package catalogue

import (
	"errors"

	"time"

	"SolarNotesAPI/biz"
	reqCatalogue "SolarNotesAPI/param/req/v1/catalogue"
	respCatalogue "SolarNotesAPI/param/resp/v1/catalogue"
	"SolarNotesAPI/resp_body"
	"SolarNotesAPI/sys_error"

	"github.com/gin-gonic/gin"
)

// Show 返回可见书籍的公开目录树.
func Show(c *gin.Context) {
	var req reqCatalogue.ShowReq
	var body resp_body.RespBody
	if err := c.ShouldBindJSON(&req); err != nil {
		body.ValidateFailed(err)
		c.JSON(http.StatusOK, body)
		return
	}

	root, err := biz.ReadCatalogue(c.Request.Context(), req.Book.ID)
	if err != nil {
		var dbErr *sys_error.DatabaseError
		switch {
		case errors.Is(err, sys_error.BookNotFoundErr):
			body.BookNotFoundError()
		case errors.Is(err, sys_error.CatalogueNotFoundErr):
			body.CatalogueNotFoundError()
		case errors.As(err, &dbErr):
			body.DBError()
		default:
			body.InternalError()
		}
		c.JSON(http.StatusOK, body)
		return
	}

	body.Success(map[string]any{"catalogue": toResponse(root)})
	c.JSON(http.StatusOK, body)
}

func toResponse(node *biz.CatalogueNode) respCatalogue.Node {
	item := respCatalogue.Node{
		ID:   strconv.FormatInt(node.ID, 10),
		Type: node.Type,
		Name: node.Name,
	}
	if node.Type == "folder" {
		children := make([]respCatalogue.Node, 0, len(node.Children))
		for _, child := range node.Children {
			children = append(children, toResponse(child))
		}
		item.FolderFields = &respCatalogue.FolderFields{
			Intro:     node.Intro,
			CreatedAt: node.CreatedAt.Format(time.DateOnly),
			Children:  children,
		}
	}
	return item
}

新增目录 DAO。直接复用 db.DB 的单数表名策略与现有 Book 模型，同一本书只需两次读取。SQL 排序由数据库完成。

package model

import (
	"context"
	"database/sql"
	"errors"
	"time"

	"SolarNotesAPI/db"

	"gorm.io/gorm"
)

var BookNotFoundErr = errors.New("visible book not found")

type Catalogue struct {
	ID            int64     `gorm:"column:id;primaryKey;autoIncrement:false"`
	BookID        int64     `gorm:"column:book_id"`
	ParentID      int64     `gorm:"column:parent_id"`
	Type          string    `gorm:"column:type"`
	Name          string    `gorm:"column:name"`
	Intro         string    `gorm:"column:intro"`
	Sort          *int32    `gorm:"column:sort"`
	DisplayStatus string    `gorm:"column:display_status"`
	CreatedAt     time.Time `gorm:"column:created_at"`
}

// ReadBookTree reads the visible book and all its nodes from one snapshot.
func (Catalogue) ReadBookTree(ctx context.Context, bookID int64) ([]Catalogue, error) {
	if db.DB == nil {
		return nil, errors.New("database connection is not initialized")
	}

	var rows []Catalogue
	opts := &sql.TxOptions{Isolation: sql.LevelRepeatableRead, ReadOnly: true}
	err := db.DB.WithContext(ctx).Transaction(func(tx *gorm.DB) error {
		var book Book
		err := tx.Select("id").Where("id = ? AND display_status = ?", bookID, "visible").Take(&book).Error
		if errors.Is(err, gorm.ErrRecordNotFound) {
			return BookNotFoundErr
		}
		if err != nil {
			return err
		}

		return tx.Select("id", "book_id", "parent_id", "type", "name", "intro", "sort", "display_status", "created_at").
			Where("book_id = ?", bookID).
			Order("sort ASC").
			Find(&rows).Error
	}, opts)
	if err != nil {
		return nil, err
	}
	return rows, nil
}

biz/catalogue.go

新增目录业务实体和组树逻辑。按父 ID 建索引后遍历一次，在隐藏分支内继续计数以校验可达性，仅将公开子项挂到返回树。建索引及遍历的时间、空间均为 O(n)。

package biz

import (
	"context"
	"errors"
	"fmt"
	"time"

	"SolarNotesAPI/model"
	"SolarNotesAPI/sys_error"
)

type CatalogueNode struct {
	ID        int64
	Type      string
	Name      string
	Intro     string
	CreatedAt time.Time
	Children  []*CatalogueNode
}

// ReadCatalogue reads the public catalogue rooted at the given book.
func ReadCatalogue(ctx context.Context, bookID int64) (*CatalogueNode, error) {
	if ctx == nil || bookID <= 0 {
		return nil, errors.New("biz.ReadCatalogue: invalid context or book ID")
	}
	var dao model.Catalogue
	rows, err := dao.ReadBookTree(ctx, bookID)
	if errors.Is(err, model.BookNotFoundErr) {
		return nil, sys_error.BookNotFoundErr
	}
	if err != nil {
		return nil, &sys_error.DatabaseError{Cause: err}
	}
	return buildCatalogueTree(bookID, rows)
}

// buildCatalogueTree expects the DAO's ascending sort order. Filtering by
// parent preserves that order within each set of siblings.
func buildCatalogueTree(bookID int64, rows []model.Catalogue) (*CatalogueNode, error) {
	if len(rows) == 0 {
		return nil, sys_error.CatalogueNotFoundErr
	}

	byID := make(map[int64]*model.Catalogue, len(rows))
	children := make(map[int64][]*model.Catalogue)
	var root *model.Catalogue
	for i := range rows {
		row := &rows[i]
		if row.ID <= 0 || row.BookID != bookID || row.ParentID < 0 {
			return nil, fmt.Errorf("book %d: invalid catalogue identity at node %d", bookID, row.ID)
		}
		if byID[row.ID] != nil {
			return nil, fmt.Errorf("book %d: duplicate node %d", bookID, row.ID)
		}
		if row.Type != "folder" && row.Type != "file" {
			return nil, fmt.Errorf("node %d: unknown type %q", row.ID, row.Type)
		}
		if row.DisplayStatus != "visible" && row.DisplayStatus != "hidden" {
			return nil, fmt.Errorf("node %d: unknown display status %q", row.ID, row.DisplayStatus)
		}
		byID[row.ID] = row
		if row.ParentID == 0 {
			if root != nil || row.Type != "folder" || row.Sort == nil || *row.Sort != 0 {
				return nil, fmt.Errorf("book %d: invalid or duplicate root %d", bookID, row.ID)
			}
			root = row
			continue
		}
		if (row.Sort == nil && row.DisplayStatus != "hidden") || (row.Sort != nil && *row.Sort <= 0) {
			return nil, fmt.Errorf("node %d: invalid non-root sort", row.ID)
		}
		siblings := children[row.ParentID]
		if row.Sort != nil && len(siblings) > 0 {
			previous := siblings[len(siblings)-1].Sort
			if previous != nil && *previous == *row.Sort {
				return nil, fmt.Errorf("parent %d: duplicate sort %d", row.ParentID, *row.Sort)
			}
		}
		children[row.ParentID] = append(siblings, row)
	}
	if root == nil {
		return nil, fmt.Errorf("book %d: catalogue root missing", bookID)
	}
	for parentID := range children {
		if parent := byID[parentID]; parent == nil || parent.Type != "folder" {
			return nil, fmt.Errorf("book %d: missing or non-folder parent %d", bookID, parentID)
		}
	}

	// Visit even unpublished subtrees so that reachability covers every row.
	type visit struct {
		row    *model.Catalogue
		parent *CatalogueNode
	}
	queue := []visit{{row: root}}
	var result *CatalogueNode
	for i := 0; i < len(queue); i++ {
		item := queue[i]
		row := item.row
		var node *CatalogueNode
		publish := row.DisplayStatus == "visible" && !(row.Type == "folder" && row.Name == "img")
		if publish && (row == root || item.parent != nil) {
			node = &CatalogueNode{ID: row.ID, Type: row.Type, Name: row.Name}
			if row.Type == "folder" {
				node.Intro = row.Intro
				node.CreatedAt = row.CreatedAt
				node.Children = make([]*CatalogueNode, 0)
			}
			if row == root {
				result = node
			} else {
				item.parent.Children = append(item.parent.Children, node)
			}
		}
		for _, child := range children[row.ID] {
			queue = append(queue, visit{row: child, parent: node})
		}
	}
	if len(queue) != len(rows) {
		return nil, fmt.Errorf("book %d: unreachable catalogue cycle", bookID)
	}
	if result == nil {
		return nil, sys_error.CatalogueNotFoundErr
	}
	return result, nil
}
